# Code-Chef-Marker
This is a chrome extension that marks a question if the question is upsolved.
For using this extension follow the given steps :-
1. Run this command to clone this repo "git clone https://github.com/Piyush-Goenka/Code-Chef-Marker"
2. Then go to google chrome and go to given url "chrome://extensions"
3. Turn on the developer mode in top right corner.
4. Then click on Load Unpacked in top left corner then select the directory which you have cloned earlier.
5. Now your extension is good to go 😁😁.
